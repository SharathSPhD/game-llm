The \texttt{kinetic-ai} package (version 1.0.0) is published on PyPI and installable via \texttt{pip install kinetic-ai}; the source repository is available at \url{https://github.com/SharathSPhD/game-llm}. Every reported number is traced to a results file in \texttt{results/} carrying a resolved-configuration SHA-256 hash and the commit that produced it, enabling deterministic reproduction. The findings ledger (\texttt{research/memory/findings.md}) documents the per-finding evidence paths, Tarka adversarial review verdicts, and operator sign-offs for each result F1–F25. Three 121M-parameter pretrained checkpoints are released on the Hugging Face Hub under the \texttt{qbz506} account:
\begin{itemize}
\setlength\itemsep{0pt}
\item \texttt{kinetic-eqlm-anytime-121m-babylm} --- the anytime-trained parity model, reaching 99.1\% of baseline;
\item \texttt{kinetic-eqlm-121m-babylm} --- the post-LN implicit-trained model;
\item \texttt{kinetic-explicitlm-124m-babylm} --- the explicit-architecture baseline.
\end{itemize} An interactive findings explorer visualizing the full experimental record is hosted at \url{https://sharathsphd.github.io/game-llm/}. Test suites include Tarka-run verification scripts; the GPU-free audit can be run on a standard CPU in under 10 minutes via \texttt{python -m pytest tests/ -q -m "not slow"}.
