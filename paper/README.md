# Kinetic AI Paper

This directory contains the arXiv-style article for Kinetic AI: Language Modeling as Equilibrium Computation.

## Build

```bash
make paper          # latexmk -pdf kinetic_ai.tex
make figures        # generate publication-quality figures
make clean          # remove build artifacts
```

## Rules

- **Fill from findings**: Sections are filled incrementally **from validated findings** at each phase closure, never from the plan. Every result number and claim must be backed by a peer-reviewed experimental finding recorded in `research/memory/findings.md`.
- **Verified references only**: Every citation must resolve to a real, verifiable work. The `references.bib` file holds only the verified entries used by the paper. Fabricated or unverifiable references must never appear.
- **Figure data**: Figures live in `figures/` and are generated by `make_paper_figures.py`, which hardcodes FROZEN constants extracted from validated findings. The script raises `SystemExit` until all numbers are backed by real runs.
- **Statistical rigor**: Tables and figures report mean ± 95% CI; comparisons use Holm–Bonferroni correction and are pre-registered where applicable.
